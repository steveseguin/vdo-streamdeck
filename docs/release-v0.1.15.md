Hold one Stream Deck button to control your OBS microphone and Caption.Ninja together. Release it to mute the microphone and pause captions. No Streamer.bot is needed.

- **Optional OBS microphone control.** Choose **Local Control > Mic > Hold to talk**, enable **Control OBS mic**, connect to OBS, and select your microphone. Use the button on its own, outside a Multi Action. [German-to-English captions and OBS setup](https://github.com/steveseguin/vdo-streamdeck/blob/main/docs/captions-and-obs.md).
- **Safer release handling.** Fast taps, profile changes, and connection failures trigger microphone cleanup. An interrupted OBS mute is retried when the connection returns.
- **Better key fit.** Icons have more space around the edges, new keys use smaller bottom-aligned text, and default hold and other long labels are shorter. Existing keys retain their saved font settings; use Arial, size 9, regular, bottom alignment if a title is cropped.
- Updated the bundled input-validation dependency.

Download **ninja.vdo.streamdeck.streamDeckPlugin** below and double-click it to install or update. Your existing keys and settings are retained.

Requires Stream Deck 6.8+, Windows 10+ or macOS 12+. Optional OBS control requires OBS Studio 28+ on the same computer. Use Chrome or Edge for Caption.Ninja's listening page.
